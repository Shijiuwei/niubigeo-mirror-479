# niubigeo Brand Assets

These logo files are for the open-source AI visibility monitor now named `niubigeo`.

## Files

- `niubigeo-mark.svg`: square app icon and favicon-style mark.
- `niubigeo-readme-hero.svg`: wide README hero using the niubigeo mark and product positioning.
- `niubigeo-logo.svg`: compact lockup for narrow spaces.
- `niubigeo-logo-horizontal.svg`: horizontal lockup for reports, docs, and wider headers.
- `niubigeo-logo-on-dark.svg`: horizontal lockup for dark backgrounds.

## Design Notes

The mark is inspired by NiubiStar's recognizable brand signals: black primary shape, warm highlight color, yellow star, and developer-growth energy.

It is not a copy of the NiubiStar mascot. `niubigeo` uses an independent geo-pin, signal-ring, and star composition to fit the open-source AI visibility audit product.

## Usage

Use `niubigeo` in lowercase for the product name. Keep result-source labels separate from the brand name, for example `Source: OpenRouter API`.
